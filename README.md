# หน้าเว็บรายงานการสอน (GitHub Pages)

ไฟล์ในโฟลเดอร์นี้เป็นสาธารณะ ห้ามใส่รหัสผ่าน โทเคน หรือข้อมูลส่วนตัวของครู

- `index.html` หน้าครู  ·  `dashboard.html` แดชบอร์ดอาจารย์ใหญ่ (คัดลอกมาจาก Index.html / Dashboard.html ของที่เก็บส่วนตัวโดย `release.sh` อย่าแก้ที่นี่)
- `config.js` ลิงก์ระบบหลังบ้าน Apps Script (/exec)  ·  `shim.js` ตัวเชื่อมกับระบบหลังบ้าน  ·  `version.json` เลขเวอร์ชันล่าสุด
